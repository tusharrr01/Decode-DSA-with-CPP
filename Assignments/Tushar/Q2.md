# (Functions And Pointers)

## Question:
- You are given a positive integer N.
- Your task is to repeatedly transform the number using a specific process until it becomes a single digit (0–9).
- Each repetition of the process counts as one transformation step.

### You must implement:
- `int transform(int* num);`
- The function receives a pointer to an integer.
- You must modify the value using the pointer.
- Return the total number of transformation steps performed.
- Do NOT use arrays, strings, or STL.
- Use only fundamentals: loops, conditions, functions, and pointers.

---

### [Step 1]: Count the digits
- Determine how many digits the number has.

### [Step 2]: Split the number into two halves
- If the number of digits is even → split equally.
- If the number of digits is odd → ignore the middle digit.
- **Example (Even digits):**  
  `123456` → `123` | `456`
- **Example (Odd digits):**  
  `12345` → `12` | `45` (ignore `3`)

*(Note: Split mathematically using division and modulus operations. Do NOT convert to string.)*

### [Step 3]: Compute two values
- **S** = sum of digits of the first half
- **P** = product of digits of the second half
- **Example:**  
  `123` | `421`  
  S = 6  
  P = 8

### [Step 4]: Create the new number
- If **S > P** → new number = S - P
- If **P > S** → new number = P - S
- If **S == P** → new number = S + P
- Update using:  
  `*num = new_value;`

### [Step 5]: Repeat
- Continue until the number becomes a single digit.

---

### Return:
- Total transformation steps.

## ✅ Test Case 1

Input:

```

```

Process:

```

S = 6
P = 8
New = 2
```

Output:

```

Final number = 2
```
